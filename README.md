# 考公资料（kgzl.net）

一个面向备考人群的**纯静态资源导航站**：公考 / 考研课程目录、网盘笔记群、课程更新日志一站式入口。

整个站点由 **单个 `index.html`** 构成，零构建、零依赖、零外部资源，可直接部署到 Cloudflare Pages。

---

## 目录结构

```
考公资料kgzl.net/
└── index.html      # 全站唯一文件（约 125 KB，二维码图片已 base64 内嵌）
```

> 公众号二维码以 JPEG `data:` URI 形式内联，因此不存在图片加载失败或防盗链问题，也不需要额外上传静态资源。

## 常见修改

### 修改 / 更换二维码

二维码是 `<img>` 标签的 base64 数据，直接替换即可：

```html
<img src="data:image/jpeg;base64,这里替换成新的base64串" alt="花生考公 公众号二维码">
```

生成 base64：

```bash
# macOS / Linux
base64 -i qrcode.jpg

# Windows PowerShell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("qrcode.jpg"))
```

若新图是 PNG，需把前缀改为 `data:image/png;base64,`。

### 修改课程链接

搜索 `https://docs.qq.com/doc/`，共 8 处（导航栏 4 处 + 卡片区 4 处），替换为新地址即可。

### 修改 QQ 号

搜索 `1620668378`，共 2 处：HTML 展示文案与 JS 复制逻辑，两处需保持一致。

### 修改配色

集中在 `<style>` 顶部的 CSS 变量：

```css
:root{
  --green:#0eaf5b;        /* 主色 */
  --green-deep:#0a7d42;   /* 深色 */
  --amber:#f6a821;        /* 强调色 */
  --bg:#faf9f5;           /* 页面底色 */
}
```
